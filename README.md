# datatypeplus

**Advanced Data Structures and Fine-Grained Reactive Containers for Python**

`datatypeplus` provides Python developers with ergonomic, expressive, and reactive data structure primitives.

## Features

- **FlexString:** Fluent, mutable string container with regex, casing transformations, and parsing.
- **NList:** Multi-dimensional sparse grid supporting labeled axes, sub-grid slicing, aggregations, and export formats.
- **EvolveList & EvolveElement:** Reactive list supporting transaction batching, computed values, event hooks, and condition triggers.
- **FlexDict & EvolveDict:** Dot-notation dictionary with auto-vivification, flattening, merging, and reactive key watching.
- **Signal, Computed, Effect:** Standalone fine-grained reactivity engine.
- **FlexTree:** Hierarchical tree structure with path searching, traversal, and dictionary export.
